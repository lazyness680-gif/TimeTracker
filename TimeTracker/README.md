# TimeTracker

Локальный канбан-тайм-трекер для Windows: доска задач с карточками, интервалы
работы, шаблоны, профиль команды, отчёты.

**MVP без авторизации:** участники команды переключаются в шапке приложения
без пароля; время записывается на выбранного участника.

## Стек

- Python 3.11+ / PySide6 (Qt6) — UI
- SQLite (stdlib) в режиме WAL
- PyInstaller — сборка portable `.exe`
- Single-instance через named mutex (повторный запуск фокусирует окно)

## Запуск из исходников

```bat
pip install -r requirements.txt
python main.py
```

БД создаётся автоматически: `data\timetracker.db` рядом с `main.py`.
Путь можно переопределить: `python main.py --db D:\tt\my.db`.

При первом запуске показывается диалог **создания команды**: название команды
и имя первого участника (пароль не задаётся — входа нет).

## Сборка portable-версии (PyInstaller)

```bat
build.bat
```

Результат: `dist\TimeTracker\TimeTracker.exe` (+ служебная папка `_internal`).

Разместите папку `TimeTracker` в месте, доступном на запись всем пользователям ПК,
например `C:\Users\Public\TimeTracker\` или `D:\TimeTracker\`. Права
администратора Windows не требуются.

## Экраны

| Экран | Что делает |
|---|---|
| **Доска** | Канбан: колонки «Новая / В работе / Завершена», карточки задач перетаскиваются мышью; двойной клик — карточка задачи с подробностями и действиями |
| **Шаблоны** | Заготовки задач + «Создать задачу» и «Быстрый старт» |
| **Мои записи** | Свои записи времени за период (фильтры по датам и задаче, открытые интервалы с живым таймером) |
| **Профиль команды** | Название команды, участники (добавить/переименовать/удалить), статистика времени за период |
| **Отчёты** | Суммарное время по участникам и задачам за период (итог, фильтры) |

В шапке — название команды, **переключатель темы** (светлая/тёмная) и
**переключатель участника** (без пароля).
Наверху — панель «Мои активные» с таймерами (обновление раз в секунду).

## Оформление

- Две темы — **светлая** и **тёмная** — с переключателем в шапке;
  выбор сохраняется в `settings` и применяется при следующем запуске.
- Палитра: синий (основной), янтарь («В работе»), зелёный («Завершена»),
  красный (высокий приоритет и кнопки «Удалить»).
- Цветные колонки канбана, карточки с цветной полосой приоритета и рамкой
  активной задачи, чередующиеся строки таблиц, стилизованные вкладки,
  поля ввода, кнопки и полосы прокрутки (единый QSS в `ui/theme.py`).

## Ключевая логика

- **Канбан и таймеры связаны:** перенос карточки в «В работе» запускает
  интервал текущего участника, в «Завершена» — останавливает его
  (с подтверждением «Завершить задачу «…»? Длительность: ЧЧ:ММ»).
  Статус по-прежнему вычисляется из интервалов: «Новая» (нет интервалов) /
  «В работе» (есть открытые) / «Завершена» (интервалы есть, открытых нет),
  поэтому даска не может разойтись с данными. Перенос в «Новая» при
  наличии интервалов запрещён — только архивирование.
- **Старт/завершение:** одновременно можно вести несколько задач; по одной
  задаче у участника — один открытый интервал; завершение закрывает только
  интервал текущего участника.
- **Видимость:** личные задачи видны только владельцу; общие — всей команде
  (равноправие участников не даёт обхода видимости).
- **Участники:** без паролей и ролей в интерфейсе; удаление мягкое — задачи
  и интервалы сохраняются, личные задачи скрываются из списков, но остаются
  в отчётах. Текущего участника удалить нельзя.
- **Переключатель участника** не трогает открытые интервалы (параллельная
  работа команды).
- **Heartbeat**: каждые 30 сек пишется `last_activity_at`; при старте
  приложения все открытые интервалы закрываются этим временем
  (`shutdown_recovery`) — корректное восстановление после выключения ПК.
- **Закрытие окна**: предупреждение «Будут закрыты N активных интервалов
  текущим временем» — закрываются интервалы **всех** участников (`app_close`).
- **Аудит** (`audit_log`): создание/переименование/удаление участника,
  переименование команды, создание/изменение/архивация задачи, старт/стоп,
  редактирование интервалов. Экрана просмотра в MVP нет, данные пишутся.

## Структура проекта

```
TimeTracker/
├── main.py                     # точка входа (--db <path>), без входа в учётку
├── build.bat                   # сборка PyInstaller
├── requirements.txt
├── timetracker/
│   ├── db.py                   # схема SQLite (WAL, индексы — раздел 6 ТЗ)
│   ├── services.py             # бизнес-логика: задачи, интервалы, команда, аудит, отчёты
│   ├── single_instance.py      # named mutex + фокусирование окна
│   ├── paths.py                # пути (portable: <exe>\data\timetracker.db)
│   └── ui/
│       ├── theme.py            # светлая/тёмная темы (QSS) + переключение
│       ├── first_run.py        # диалог создания команды (первый запуск)
│       ├── main_window.py      # шапка, переключатель участника, панель, таймеры
│       ├── board_tab.py        # канбан-доска: колонки, карточки, drag&drop
│       ├── templates_tab.py    # шаблоны + «Быстрый старт»
│       ├── records_tab.py      # «Мои записи» — свои записи за период
│       ├── team_tab.py         # профиль команды: название, участники, статистика
│       ├── reports_tab.py      # отчёт по участникам за период
│       ├── intervals_dialog.py # интервалы задачи, редактирование
│       └── dialogs.py          # задача, карточка задачи, шаблон, интервал
└── tests/test_acceptance.py    # 12 сценариев + доп. проверки + UI (offscreen)
```

## Тесты

```bash
python tests/test_acceptance.py   # из корня проекта (рядом с папкой TimeTracker)
```

Покрывают сценарии тайм-трекинга и канбана, участников и профиль команды,
heartbeat-восстановление, single-instance, аудит, записи времени и UI (offscreen).

## Ограничения MVP

Один ПК и общая локальная БД; без сети/синхронизации, экспорта CSV, бэкапов,
трея, автозапуска, тегов и комментариев; интерфейс только русский.
Авторизация (вход, пароли, роли) в MVP не используется.
