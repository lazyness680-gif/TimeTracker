Первая версия TimeTracker: канбан-доска, карточки задач, интервалы, профиль команды, отчёты и две темы. Без авторизации.

## Как запустить

1. Скачайте `TimeTracker-1.0.0-win64.zip`.
2. Распакуйте в любую папку (например, `C:\Users\Public\TimeTracker`).
3. Запустите `TimeTracker.exe` — при первом запуске создайте команду.

Установщик и права администратора не нужны. Данные хранятся в папке `data` рядом с exe.

**Требования:** Windows 10/11 x64.
